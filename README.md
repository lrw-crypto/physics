# 物理刷題站

技高物理 B 上的分節練習與錯題本。網站由 GitHub Pages 直接提供靜態檔案。

- 開啟 [物理刷題站](https://lrw-crypto.github.io/physics/) 即可練習。
- `questions.json` 記錄章節、題目、原卷編號、答案與解析。題目中的 `{{img:檔名}}` 連到 `assets/figures/` 的圖表或照片。
- 題庫目前有 423 題。第 1 章已逐題對照 MOSME 教師出題系統的 PC12521 題庫，共 105 道原題，包含 1-1 的 26 題和 1-2 的 79 題。第 2 至 8 章使用既有題庫。
- 第 1 章每道題的 `publisherRefs` 記錄原始分類和題號。範例練習 4 題、課後習題 20 題、歷屆試題 10 題、補充測驗卷第 1 回 20 題、補充試題 51 題。MOSME 在不同來源分別收錄的題目各自計數。
- `questions.json` 的 `questionAliases` 保留仍適用的舊題號對應，讓學生在錯題本看到過去的錯題。
- 結構化文字保留可選取的文字與數學符號。非選題提供參考解，學生對照後自行標記結果。
- `config.js` 指向學生帳號與錯題紀錄服務。服務持久化資料在 Sites 的 D1 資料庫。訪客紀錄留在當前瀏覽器。
