# 物理刷題站

技高物理 B 上的分節練習與錯題本。網站由 GitHub Pages 直接提供靜態檔案。

- 開啟 [物理刷題站](https://lrw-crypto.github.io/physics/) 即可練習。
- `questions.json` 記錄章節、題目、原卷編號、答案與解析。題目中的 `{{img:檔名}}` 連到 `assets/figures/` 的圖表或照片。
- 題庫有 1,130 道原題，已逐章、逐節、按來源與題型對照 MOSME 教師出題系統的 PC12521 題庫。
- `publisherRefs` 記錄題目的原始分類和題號。MOSME 分開收錄的題目各自計數。需接續上題的原題附起始題文與圖，出現在單題練習時仍可作答。
- `questionAliases` 和 `archivedQuestions` 讓舊錯題繼續可用。舊版修訂的輻射劑量題仍可從既有錯題紀錄開啟。
- 題幹、選項和填充題答案使用可選取的文字與數學符號。圖表、照片和原站部分解析公式使用原始圖檔。非選題提供參考解，學生對照後自行標記結果。
- `config.js` 指向學生帳號與錯題紀錄服務。服務持久化資料在 Sites 的 D1 資料庫。訪客紀錄留在當前瀏覽器。
