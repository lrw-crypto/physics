# 物理刷題站

技高物理 B 上的分節練習與錯題本。網站由 GitHub Pages 直接提供靜態檔案。

- 開啟 [物理刷題站](https://lrw-crypto.github.io/physics/) 即可練習。
- `questions.json` 記錄章節、題目、原卷編號、答案與解析。題目中的 `{{img:檔名}}` 連到 `assets/figures/` 的圖表或照片。
- 題庫目前有 372 題。教師本第 1 章的範例練習 4 題、課後習題 20 題，及教師本導覽引用的正式練習 17 題，均保留原題號。
- 同一情境、數據和所求相同的重複題目只保留一次。跨來源重複題保留教師本版本，同卷重複題保留涵蓋完整作答要求的版本。
- `questions.json` 的 `questionAliases` 將已合併的題號對應到保留題號，讓學生仍能在錯題本看到過去的錯題。
- 第 1 章目前有 54 題。MOSME 截圖所列的 105 題尚缺可核對題文 51 題，包括歷屆試題 10 題、補充測驗卷第 1 回 20 題、補充試題單選 21 題。
- 原卷若有答案或單位明顯誤植，題庫修正並在適用處的解析標註。補充單選第 52 題改為 B，第 140 題依現行標準補入正確選項，填充第 27 題排除僅有形變的選項。
- 結構化文字保留可選取的文字與數學符號。問答題提供參考解，學生對照後自行標記結果。
- `config.js` 指向學生帳號與錯題紀錄服務。服務持久化資料在 Sites 的 D1 資料庫。訪客紀錄留在當前瀏覽器。
